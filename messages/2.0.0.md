Breaking changes:

- The key used to override LSP-PowerShellEditorServices settings in project settings has changed from `PowerShellEditorServices` to `LSP-PowerShellEditorServices`.
  If you use project-specific overrides for LSP-PowerShellEditorServices, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "PowerShellEditorServices": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-PowerShellEditorServices": {
                  // ...
              }
          }
      }
  }
  ```
